# 🔐 Générateur de mots de passe (Python)

Petit script en Python pour générer des mots de passe forts et aléatoires.

---

## 🎯 Fonctionnalités

- Génère des mots de passe de n’importe quelle longueur
- Utilise lettres, chiffres et caractères spéciaux
- Simple, rapide, sans interface

---

## ▶️ Utilisation

```bash
python password_generator.py
